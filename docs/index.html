Stagio Lite

Beta 1.1

给自己讲投影片的人：讲员、老师、做报告的人。For people presenting their own slides: speakers, teachers, anyone giving a talk.

  • 手机当翻页器，看到当前页、下一页、备注和计时Your phone as the clicker, with the current and next slide, notes and timers
  • 黑屏/白屏、投影上的真实画面、开场前检查Black and white screen, the real projector picture, a pre-event check
  • 只要打开文件、手机扫码，就能开始Open the file, scan the code, go

Stagio Standard

Beta 1.1

一个人在后面控投影片、音乐和投影输出。One person running slides, music and the projector.

  • Lite 的全部，加上：Everything in Lite, plus:
  • Spotify 音乐、平滑淡入淡出到指定音量Spotify music, smooth fades to any level
  • 音响/耳机切换、系统音量、投影模式Audio device, system volume, projector mode
  • Cue：一个按钮执行一串动作，或翻到某一页自动执行Cues: one button for a sequence of steps, or automatically at a slide

Stagio Extra

Beta 1.2

负责整场活动的人。For whoever runs the whole event.

  • Standard 的全部，加上：Everything in Standard, plus:
  • 节目流程：按一下就切到下一段的文件、音乐和画面Run of show: one press goes to the next part's file, music and screen
  • 投影机上的开场倒数，到点音乐淡出、自动开始Opening countdown on the projector; the music fades out and the event starts at zero
  • 每段剩多少时间、整场快了或慢了多少Time left in each part, and how far ahead or behind the event is
  • 讲台提示屏：讲员的手机/平板看到这一页、下一页、备注和剩余时间，还能收到你发的讯息Stage display: the speaker's phone or tablet shows this slide, the next, the notes and the time left, and your messages

Windows

  • Windows 10 / 11、PowerPoint 2016 或 Microsoft 365；放音乐需要 Spotify 应用（Standard 和 Extra）Windows 10 / 11, PowerPoint 2016 or Microsoft 365; music needs the Spotify app (Standard and Extra)
  • 如出现“Windows 已保护你的电脑”：点“更多信息 → 仍要运行”（安装程序还没有代码签名，正在向 SignPath Foundation 申请开源项目的免费签名）。If Windows says "Windows protected your PC": More info → Run anyway (the installer is not code-signed yet; free signing for open-source projects has been applied for at SignPath Foundation).
  • 双击后没反应或提示无法访问：防毒软件还在检查新文件，等几分钟再双击。Nothing happens, or "can't access": antivirus software is still checking the new file; try again in a few minutes.
  • Stagio 以前叫 OneDesk。已经装了 OneDesk：装同一个版本的 Stagio（例如 OneDesk Extra → Stagio Extra）就会直接升级，设置、PIN、Cue 都保留；0.x 的 OneDesk 装 Standard。Stagio used to be called OneDesk. With OneDesk installed, install the same edition of Stagio (OneDesk Extra → Stagio Extra): it updates it and keeps the settings, PIN and cues. OneDesk 0.x: install Standard.
  • 三个版本可以都装，资料共用（设置、PIN、Cue），同一时间开一个。All three can be installed; they share settings, PIN and cues, and one runs at a time.

Mac

测试版Test version
  • 功能和 Windows 版基本相同，但还没有和真正的 PowerPoint 一起测试过，正式使用前请先试一次。Nearly the same features as on Windows, but not yet tested with PowerPoint on a real Mac: try it before an event.
  • 第一次打开：在“应用程序”里按住 Control 点它 → 打开（没有 Apple 签名）。如提示“已损坏”，在“终端”执行 xattr -cr "/Applications/Stagio Standard.app"（换成你装的版本）。First start: Control-click the app in Applications → Open (it is not signed by Apple). If it says "damaged", run xattr -cr "/Applications/Stagio Standard.app" in Terminal, with your edition's name.
  • 投影画面实时截取需要 macOS 14（Sonoma）以上，第一次用时要允许“屏幕录制”。The live projector picture needs macOS 14 (Sonoma) or later and the Screen Recording permission.
  • 和 Windows 不同：投影模式只有同步和延伸（只用投影机时合上盖子）；没有 Stagio Wi-Fi，改用手机热点；不需要“加速”。Different from Windows: Duplicate and Extend only (close the lid for the projector only); no Stagio Wi-Fi, use the phone's hotspot; no speed-up needed.

手机 · 平板Phone · tablet

不用下载No download

手机和平板是遥控器，用网页打开，不用安装。Phones and tablets are the remote, in the browser; nothing to install.

  1. 在电脑的 Stagio 点 Remote，用手机相机扫二维码。On the computer, click Remote in Stagio and scan the code with the phone's camera.
  2. 再选“加到主屏幕”，以后像 App 一样从图标打开。Then "Add to Home Screen": from then on it opens like an app.

没有 Wi-Fi 时：Stagio 可以开自己的 Wi-Fi（Windows），或用手机热点（Mac），或用蓝牙（Android）。No Wi-Fi: Stagio's own Wi-Fi (Windows), the phone's hotspot (Mac), or Bluetooth (Android).
