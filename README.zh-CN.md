# Stagio 一人控台

[English](README.md) · 中文

把原本两到三个人的工作（放音乐、翻投影片、管投影/音响输出）集中在一个界面，由一个人掌控。

## 三个版本（Beta 1.0 起）

同一个程序分成三个版本，按“谁在用”来分，一个比一个大。每个版本只显示自己的功能，用不到的功能不会出现，也不用设定。

| | Stagio Lite | Stagio Standard | Stagio Extra |
| --- | --- | --- | --- |
| 给谁用 | 自己讲自己投影片的人（讲员、老师、做报告） | 一个人在后面控投影和音乐（就是 0.x 的 OneDesk） | 负责整场活动的人 |
| 翻页、黑屏/白屏、备注、计时、真实缩略图、手机遥控、开场前检查、加速、连不上时的备援 | 有 | 有 | 有 |
| 音乐、淡入淡出、音量过渡、音频输出、投影模式、Cue、自动 Cue | — | 有 | 有 |
| 节目流程、开场倒数、讲台提示屏和控台讯息（见下方） | — | — | 有 |

- **各自下载，资料共用**：三个版本可以同时装在一台电脑上（开始菜单里各有一个图标），但同一时间只能开一个，因为它们控制的是同一个 PowerPoint。已经开着一个，再开另一个时，开着的那个会问要不要换过去；换过去时设置、PIN、Cue、节目流程都在，不用重设。小版本用不到的资料（例如 Extra 的节目流程）会原样保留。
- **版本号**：0.x 都算 alpha。Beta 起叫 Beta 1.0、1.1、1.2、1.2.1、2.0……：修正问题加最后一位，加新功能加中间一位，大改动加第一位。三个版本和 Windows、Mac 的号码各自往上加，只有改到的才更新（`editions.json`）。够稳定后转正式版，从 1.0 重新开始，不再写 Beta。
- **从 OneDesk 升级**：Stagio 在 2026 年 11 月之前叫 OneDesk。装同一个版本的 Stagio（例如 Stagio Extra）就会直接覆盖升级原来的 OneDesk Extra（同一个“应用”登记、同一个文件夹），旧的 OneDesk.exe 会被删掉，开始菜单、桌面和任务栏上的快捷方式会改成 Stagio，设置、PIN、Cue、节目流程全部保留（资料夹仍然是 `%APPDATA%\OneDesk`）。0.x 的 OneDesk 由 Stagio Standard 接手。

## 安装与下载

**下载页面：https://ngxu.github.io/stagio/**（三个版本的 Windows 安装程序和 Mac 测试版、手机说明；可以直接把这个网址发给别人）。

| 设备 | 角色 | 怎么装 |
| --- | --- | --- |
| **Windows 电脑**（接投影机、运行 PowerPoint 的那台） | 主控端 | 从下载页面选一个版本下载，或执行 `dist\Stagio-<版本>-Setup-<版本号>.exe`（例如 `Stagio-Extra-Setup-1.0.0-beta.exe`）安装，桌面和开始菜单会有它的图标。不需要另外安装 Node.js |
| **手机 / 平板**（iPhone、Android） | 遥控端 | 在主控台点 **Remote**，用手机扫码打开，再“加到主屏幕”（步骤写在 Remote 对话框里），之后从图标打开。iPhone 会全屏显示；Android 因为连线是 HTTP，可能仍带浏览器地址栏 |
| **Mac** | 遥控端 | 用 Safari 打开 Remote 显示的网址，再选“文件 → 添加到程序坞” |
| **Mac**（直接控制 Mac 版 PowerPoint） | 主控端，**测试版** | 从下载页面选一个版本下载（Apple 芯片 / Intel），见下方“Mac 测试版” |

需要：Windows 10/11、PowerPoint（Office 2016 / 365）。放音乐用你平常用的播放程序就可以（音乐 App、媒体播放器或浏览器）。

**安装时的蓝色警告**：安装程序没有代码签名，所以第一次执行时 Windows 会显示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”即可。安装程序是在 GitHub 上从公开的源代码自动打包的，下载页的发布说明列出了每个文件的 SHA-256，可以用来核对下载的文件。

**双击后没反应，或显示“Windows 无法访问指定设备、路径或文件”**：这是防毒软件还在检查这个新文件，它会先挡住还没检查完的、没签名的程序。等几分钟再双击就可以，不需要关掉防毒，也不需要加例外。刚装好之后马上卸载，也可能遇到同样的情况。

**更新时 Stagio 还开着**：安装程序会提示 Stagio is still open，关掉 Stagio 窗口再按 Retry 即可（正在放映的投影片不受影响）。

**卸载**：Windows 设置 → 应用 → 已安装的应用 → Stagio Lite / Standard / Extra → 卸载。只会删掉那个版本自己的程序文件和快捷方式；设置、Cue、节目流程和加速前的备份会留在 `%APPDATA%\onedesk`（其他版本也在用），缩略图缓存在 `%USERPROFILE%\.onedesk`，全部版本都不用了的话再自己删掉这两个文件夹。

**资料存放位置（安装版，三个版本共用）**：设置、PIN、Cue、节目流程存在 `%APPDATA%\onedesk\config.json`（上一版自动留作 `config.backup.json`；文件损坏时会自动用备份恢复），日志在同一个文件夹的 `stagio.log`，缩略图缓存在 `%USERPROFILE%\.onedesk\thumbs`。

### 打包安装程序（开发者）

```bash
npm install
```

```bash
npm run dist:win
```

输出三个安装程序 `dist\Stagio-Lite-Setup-<版本号>.exe`、`Stagio-Standard-Setup-…`、`Stagio-Extra-Setup-…`（版本号在 `editions.json`），大约要 15 分钟（压缩最花时间）。这个命令执行 `build\make-installer.js`：先用 electron-builder 把程序打包一次到 `dist\win-unpacked`，再用 NSIS 为每个版本编译我们自己的安装脚本 `build\installer.nsi`；安装时写入 `resources\edition.json`，程序靠它知道自己是哪个版本。加上 `-- --edition=extra` 只做那一个（可以重复），加上 `-- --no-pack` 直接用现有的 `dist\win-unpacked`，只重做安装程序。

为什么不用 electron-builder 自带的安装程序：它在打包过程中会执行一个刚编译出来的程序来产生卸载程序，有些防毒软件会挡住这种刚产生、没签名的程序，打包就失败（`__uninstaller.exe -> no files found`）。我们的脚本在打包时不执行任何程序，卸载程序在安装时才写出来。每个版本有自己的“应用”登记（GUID 写在 `make-installer.js`，不能改）、文件夹和快捷方式；Standard 沿用 0.x 的登记，所以会直接覆盖升级。

NSIS 用的是 electron-builder 缓存里的那一份（`%LOCALAPPDATA%\electron-builder\Cache\nsis-*`）。新电脑上如果还没有，先执行一次 `npx electron-builder --win nsis` 让它下载（这一步本身失败也没关系），或安装 NSIS 3，或把 `STAGIO_MAKENSIS` 设成 `makensis.exe` 的路径。

如果 `npm install` 之后找不到 `node_modules\electron\dist\electron.exe`（新版 npm 会挡掉安装脚本），先执行 `node node_modules\electron\install.js`。修改图标请改 `build\make-icons.ps1`，再执行 `npm run icons`。

### 不安装、直接运行（开发用）

双击 `Start Stagio.bat`，或执行 `npm start`（需要 Node.js 18+），会用 Edge 应用模式打开主控台；资料存在项目的 `data\` 文件夹。也可以执行 `npm run app`，以桌面 App 的形式运行。直接运行时是 Standard；设环境变量 `STAGIO_EDITION=lite` 或 `extra` 可以当作那个版本运行。

### Mac 测试版

Mac 版用 AppleScript 控制 Mac 版 PowerPoint，以及“音乐”App 或 Spotify，其余部分（屏幕、音频输出、截取放映画面、蓝牙）由 Stagio 自带的 Mac 小程序完成（`mac/helper/main.swift`，用 Apple 自己的 ScreenCaptureKit、CoreGraphics、CoreAudio、CoreBluetooth）。它在 GitHub 的 Mac 上自动打包，并在那里检查过：小程序的每个指令都有回应、不会崩溃，能真正截取一个窗口（用“文本编辑”代替放映窗口）并存成投影片图片，主控台能启动，“Mac check”能跑完。**但还没有和真正的 PowerPoint、投影机一起测试过**（GitHub 的 Mac 上没有 PowerPoint），正式使用前请先按下面的“Mac 测试清单”试一次。

打包（Mac 的安装文件只能在 Mac 上产出）：源代码在 GitHub 仓库 `ngxu/stagio`，推送一个 `v*` 标签（例如 `v1.0.0-beta`），或在 Actions 页面点 “Mac build → Run workflow”，GitHub 就会在它的 Mac 上同时打包 Lite、Standard、Extra 三个版本，每个都有 Apple 芯片和 Intel 两种（工作流程在 `.github/workflows/mac.yml`，产物叫 `stagio-mac-<版本>`）。也可以在一台 Mac 上自己执行（打出来的是 Standard）：

```bash
npm install && npm run dist:mac
```

GitHub 打出来的文件叫 `Stagio-Extra-1.0.0-beta-mac-<arm64|x64>.dmg` 这样。每个版本是独立的 App（`Stagio Lite.app` 等），可以同时放在“应用程序”里，资料共用（`~/Library/Application Support/OneDesk`）；macOS 的权限（屏幕录制、蓝牙等）要每个版本各自允许一次。这些版本没有 Apple 签名，第一次打开要在 Finder 里右键 → 打开；如果提示“已损坏”，执行 `xattr -cr "/Applications/Stagio Extra.app"`（换成你装的版本）。

#### Mac 需要的权限（第一次用到时 macOS 会问）

| 权限 | 用来做什么 | 没有它会怎样 |
|---|---|---|
| 自动化：控制 PowerPoint、“音乐”或 Spotify、System Events | 翻页、黑白屏、开始结束放映、读取页面；音乐 | 无法控制，请选“好” |
| 屏幕与系统录音（Screen & System Audio Recording） | PROGRAM 实时画面、放映中的真实缩略图 | 主控台会提示去哪里打开；打开后要退出再重开 Stagio |
| 蓝牙 | 蓝牙遥控 | 蓝牙卡片显示没有权限 |
| 辅助功能（Accessibility） | 只有“Mac check”读取 PowerPoint 的菜单时用 | 检查报告里这几项显示错误，其余照常 |

#### Mac 和 Windows 功能对照

| 功能 | Mac |
|---|---|
| 翻页、黑屏/白屏、开始/结束放映、跳页、Cue、自动 Cue、计时器、备注 | 有 |
| PROGRAM 实时画面（不管投影机多大都看到完整画面） | 有，需要 macOS 14 以上和“屏幕录制”权限 |
| 放映中修改、插入、删除页面后自动更新 | 有：放映中用截取的画面当缩略图（标 DRAFT，直到和导出的图片对上），没放映时整份导出 |
| 音乐三种模式、淡入淡出、从指定音量淡到指定音量、系统音量平滑过渡 | 有 |
| 切换音频输出设备 | 有（不再需要另外安装 SwitchAudioSource） |
| 投影模式 | 只有 Duplicate（同步）和 Extend（延伸）。Mac 不能用软件关掉某一个屏幕：只要投影机，就接上电源、键盘和鼠标后合上笔记本盖子 |
| 蓝牙遥控（Android Chrome） | 有，和 Windows 用同一个网页 |
| Stagio 自己的 Wi-Fi | macOS 不允许 App 开 Wi-Fi 网络。改用手机热点：Remote 对话框里有步骤，Mac 连上手机的热点，手机再扫码 |
| 加速（Canva 文件） | 不需要：Mac 版 PowerPoint 没有这个慢的问题 |
| 隐藏演示者视图、选择放映屏幕、动画步数 | 还没有：Mac 版 PowerPoint 的这几项要先看那台 Mac 的“Mac check”报告才能做（见下） |

#### Mac 测试清单

1. 从下载页面装好 Mac 测试版，打开一份投影片，在 Stagio 里打开同一份文件，等缩略图出来。
2. 开始放映（接投影机或第二个屏幕更好），用电脑和手机各翻几页、黑屏、白屏、结束放映。
3. 看 PROGRAM 画面是否完整、和投影一样；macOS 问屏幕录制权限时允许，然后重开 Stagio。
4. 放映中改一页的文字，看 Stagio 的缩略图会不会在几秒内更新。
5. 播放音乐，试淡出、淡入、从指定音量淡到指定音量，听有没有杂音。
6. 投影模式试 Duplicate 和 Extend；Remote → 蓝牙 → Start，用 Android Chrome 连接。
7. **Settings → Mac check → Run Mac check**：放映前跑一次、放映中再跑一次，按 Copy，把两段文字发回来。报告只读取，不改任何东西（里面有打开的文件名）。

## 功能

| 区块 | 能做什么 |
| --- | --- |
| 投影片 | 侦测已打开的 PowerPoint、开始/结束放映、上下页、跳页（点缩图）、黑屏/白屏；显示 PROGRAM（投影上的画面）、PREVIEW（下一页）、讲者备注（字号可调）、当前页的动画步数、放映计时；打开文件可用系统文件窗口、最近文件或拖放；在 Windows 上特别慢的文件可一键加速（直接改文件，或另存加速副本），外观不变 |
| 音乐 | 任何正在放音乐的程序（音乐 App、媒体播放器、浏览器……）：播放/暂停/切歌/拖进度、音量、**淡出/淡入**、**从指定音量淡到指定音量**；歌单直接在那个程序里选 |
| 输出 | 切换 Windows 音频输出设备（音控台/喇叭/耳机）、系统音量（平滑过渡，不会突然跳）、静音；投影模式（仅电脑/复制/扩展/仅投影）；选择投影片放映在哪个屏幕；隐藏 PowerPoint 自己的演示者视图 |
| Cue | 一个按钮执行一串动作，例如「音乐淡出 → 开始放映第 1 页」。按数字键 1–9 触发（也可以改成要按 Shift + 1–9），可在 Cues 栏的 Edit 里自定；也可以设成翻到某一页时自动执行 |
| 开场前检查 | 右上角 **Check**：一个画面列出文件、缩略图、慢文字、投影机、演示者视图、声音、音乐、自动 Cue、手机是否都准备好 |
| 版面 | 拖动分隔线调整各区大小、隐藏用不到的区块、左右互换；每台电脑各自保存 |
| 手机遥控 | 网页版，不需要安装 App。点右上角 Remote：手机连上同一个 Wi-Fi，用相机扫二维码；或者在手机浏览器输入显示的网址，再输入 6 位数 PIN。PIN 连续输错 8 次会锁 5 分钟。手机顶部有 Awake（保持亮屏）和 Full（全屏）两个按钮；顶栏和 Prev/Black/White/Next 固定在屏幕上（可在 Settings 关掉）。**没有 Wi-Fi 时**：Stagio 自己开 Wi-Fi，或用蓝牙（Android） |

快捷键在主控台右上角 Keys 查看。翻页笔（PgUp/PgDn、`.` 黑屏）在主控台窗口位于前台时可直接使用。

## 节目流程与开场倒数（Stagio Extra）

把一场活动排成几段（Run of show），按一下 **Next part**（或键盘 **G**），就切到下一段需要的文件、音乐和画面。

**排流程**：顶部 Run 栏点 **Edit…** → **New**，会先给一个常见的流程（倒数、欢迎、讲员、中场、第二位讲员、散场音乐），照自己的活动改：每段一个名称、类型和预定分钟数，可以上下移动、删除、加段。下次同样结构的活动按 **Duplicate** 复制一份，只换文件。

| 类型 | 这一段开始时 Stagio 做什么 |
| --- | --- |
| Slides | 打开指定的文件，从指定的那一页开始放映；上一位讲员的放映随后结束（投影上不会露出桌面）。可选：音乐同时淡出 |
| Countdown | 在投影机上全屏显示倒数（到某个时间，例如 10:00；或预定的分钟数），上面一行标题（例如 Starting soon），下面轮流显示几句通知。可选：音乐淡入；到 0 时音乐刚好淡出完，再自动进入下一段 |
| Music | 投影变黑屏（如果正在放映），音乐淡入。中场、进场、散场用 |
| Manual | 只计时，什么都不切换（例如主持人讲话） |

每一段还可以顺便执行一个 Cue（Also run cue）。

**活动中**：Run 栏显示每一段（红色是现在这一段，变淡的是已经过去的，底下有绿线的表示文件已经在后台打开好），现在这一段还剩多久（超时变琥珀色，超过 2 分钟变红色），以及整场比预定快或慢多少。点某一段要点两下（第一下会问 Go here?），防止误触。**Back** 回到上一段，**Stop** 结束流程（投影片不会被关掉）。

- 下一段的文件会在这一段进行时先在后台打开（不开窗口，不会盖住 Stagio），所以切换很快：实测从一份文件切到下一份文件约 0.6 秒，只有 PowerPoint 还没开的第一份要几秒。
- 文件找不到、没选文件时，Run 栏用红字说明，开场前检查（Check）也会列出来。
- Stagio 重开后，流程会停在原来那一段继续计时（不会重做那一段的动作）。
- 倒数画面需要第二个屏幕（投影机设成“扩展”）。只有一个屏幕（或“复制”模式）时，倒数会以普通窗口显示在这台电脑上，方便检查，但不会全屏盖住主控台。
- 手机上也有 Run 栏：显示现在这一段、剩余时间、快慢，和 Next part 按钮。

## 讲台提示屏与控台讯息（Stagio Extra，Beta 1.1 起）

讲员或主持人把手机/平板放在讲台上，看到投影上的这一页、下一页、放大的备注和剩余时间；控台可以发一句话给他（例如“还有 5 分钟”）。

**连接**：控台点 **Remote**，在 **Stage display** 用讲员的手机/平板扫码；或打开显示的网址，输入**提示屏 PIN**（和控台的 PIN 不同）。提示屏只能看，不能翻页、不能控制音乐，也打不开控台；控台的 PIN 也不会因此外泄。可以同时开好几个（讲员、主持人、乐手）。

**提示屏上**：
- 顶部：节目流程的这一段和剩余时间（超时变琥珀色/红色），没有流程时显示这一段已经多久；还有现在的时间。
- 投影上的这一页（黑屏/白屏时会标出来）、下一页、备注（A−/A+ 调字号，每台设备各自记住）。
- **Awake** 让屏幕保持亮着（默认开，第一次点一下屏幕就生效），**Full** 全屏。连线中断时显示大字“Not connected”并自动重连。

**发讯息**：控台右上角 **Stage**：
- 点现成的讯息（可在 “Change the ready-made messages” 里修改），或自己输入一句再按 Send。
- 讯息先在提示屏上全屏闪出，之后留在顶部，直到按 **Clear**。讲员点一下表示看到了，控台上会显示 **Seen**；Stage 按钮在未读时是琥珀色，已读是绿色。
- 实测从按下到出现在提示屏上约 0.1 秒。
- 勾选 **The speaker can change slides**，提示屏底部会出现 Prev/Next，让讲员自己翻页（默认关）。

蓝牙遥控不支持提示屏（蓝牙太慢，传不了图片）。没有 Wi-Fi 时用 Stagio Wi-Fi（Windows）或手机热点（Mac），Remote 里的提示屏二维码会跟着换成那个网络的网址。

## 打开文件

点 Slides 栏的 **Open…**：

- **Browse this PC…**（只在桌面 App 里有）：弹出 Windows 的“打开”窗口，直接选文件。
- **Recent**：最近用过的 8 个文件，点一下就打开。没有打开任何文件时，主画面中间也会列出最近的 5 个。文件被移走或删除后，点它会提示找不到，并从列表里移除。
- **File path**：贴上完整路径。
- **拖放**（只在桌面 App 里有）：把 .pptx 拖到 Stagio 窗口的任何位置。

手机和浏览器里只能用 Recent 或贴路径，因为网页拿不到电脑上文件的位置。

## 开场前检查（Check）

右上角的 **Check** 按钮会把开场前要确认的事列在一个画面里，每一项有颜色：绿色是准备好了，琥珀色要看一下，红色是这样没法用，灰色是用不用都可以。按钮本身也会变色：全部准备好时是绿色的 CHECK，有要看的项目时是琥珀色并写着数目（例如 CHECK · 2）。

| 项目 | 检查什么 | 可以直接按的 |
| --- | --- | --- |
| Presentation | PowerPoint 有没有开、文件有没有打开、是不是停在“受保护的视图”；同时开了好几个文件时会提醒你确认是哪一个 | Open… / Enable editing |
| Slide images | 缩略图是不是都做好了，还要多久 | |
| Speed in PowerPoint | 这个文件在 Windows 上会不会翻页很慢 | Speed up… |
| Projector | 有没有接上第二个屏幕（扩展模式），投影片会放在哪个屏幕 | Extend |
| Presenter View | 接了投影机时，PowerPoint 的演示者视图会不会盖住 Stagio | Hide it |
| Sound | 目前的输出设备、是否静音、音量是否太低 | Unmute |
| Music | 有没有程序在放音乐、Stagio 能不能控制它 | 打开上次用的播放程序 |
| Cues | 这份文件里有几个自动 Cue；Auto 是否关着；绑定的页面是否被删掉 | Turn Auto on / Edit cues |
| Remote | 有几台手机连着 | Connect… |

清单会随时更新（例如缩略图还在做时，进度会一直变）。它**检查不到**投影机和喇叭实际显示、播放的情况：开场前请看一眼投影画面，放几秒音乐试试。写在讲者备注里的 `[cue: …]` 标记要翻到那一页才读得到，所以不算在 Cues 那一项里。

## 放映计时器

放映开始后，右上角（手机在翻页按钮上方）出现三个计时：

- **SHOW**：这场放映已经进行多久。Stagio 启动时放映已经在进行的话，前面会加 `≥`，表示至少这么久。
- **SLIDE**：目前这一页停留了多久（窗口较窄时不显示）。
- **第三个**：这一段进行了多久。放映开始时从 0 开始；之后每执行一个 Cue（手动或自动）就重新计时，并显示那个 Cue 的名称，例如诗歌、讲道、中场。要在其他时间点重新计时，点它两下（第一下显示 Restart?）。

计时以主控电脑的时钟为准，所以手机自己的时间不准也没关系。放映结束后计时隐藏。

## 讲者备注字号

Notes 右上角的 **A−** / **A+** 调整备注文字大小（11 到 40 点）。每台设备各自记住，例如讲台上的平板可以设得很大，主控电脑保持小字。

## 动画步数

投影中的那一页如果有“单击时”播放的动画，PROGRAM 右上角会显示 `BUILD 2/5`（已播 2 步，共 5 步）。还有动画没播完时，Next 按钮显示 **NEXT BUILD**，PREVIEW 旁显示 `AFTER 3 BUILDS`，表示再按几下才会换页。往回翻到有动画的页时，那一页会是全部播完的状态（PowerPoint 本身的行为）。

## 加速（Windows 上特别慢的 Canva 文件）

有些从 Canva 导出的文件，在 Windows 版 PowerPoint 里翻一页要好几秒（Mac 不会）。以我们实际遇到的一套 Canva 投影片为例，原因是每页背景约 2,800 个带元音符号的希伯来文装饰字，而它用的字体（Helvetica Now）没有希伯来字母，PowerPoint 每画一次都要逐字找替代字体。

Stagio 的做法是把这些装饰文字换成一张透明图片，摆在完全相同的位置和图层，画面看不出差别。实测同样几页：

| | 放映翻页（中位数） | 生成一张缩略图 |
| --- | --- | --- |
| 原样 | 3–9.5 秒 | 2–6 秒 |
| 加速后 | 约 0.02–0.03 秒 | 约 0.3–1 秒 |

Stagio 打开文件时会自动检查：本机文件直接读文件，不占用 PowerPoint；从 OneDrive / SharePoint 打开的文件则通过 PowerPoint 检查一次（不在放映中进行）。发现这种文字，Slides 栏会出现琥珀色的 **SLOW IN POWERPOINT · SPEED UP**。点它会先说明情况，再让你选：

**Speed up this file（直接加速这个文件，适合多人共享的文件）**

- 改的是文件本身，所以还是同一个文件。如果文件放在 OneDrive / SharePoint 并开着自动保存，所有共享的人都会拿到这个改动，之后继续一起编辑。
- 这个按钮要**按两次**（第二次显示 Confirm: change this file）。
- 开始前，先把文件当前的样子备份到这台电脑（安装版在 `%APPDATA%\onedesk\backups`，只在本机，不会同步出去，保留最近 5 份）。本机文件且没有未保存的修改时，备份和原文件逐字节相同。
- 图片先在一份临时副本上做好、核对好，最后才放进文件本身，所以文件真正被改动的时间只有最后约半分钟。
- 放进去之前会逐页核对：那段文字（内容和位置）如果在处理期间被别人改过，那一页就不动，完成后会列出是哪几页，可以再做一次。
- 完成后自动保存。文件如果是以只读方式打开的，会直接拒绝。

**Make a faster copy（做一份加速副本）**

- 在原文件旁边另存一份 `<文件名> (fast).pptx`。**原文件完全不改**（不改内容，也不会被标成“已修改”）。
- 完成后，副本会在 PowerPoint 里打开，并在 Stagio 里选好，放映请用副本。
- 副本是独立的文件：之后别人在原文件里的修改不会进到副本；放映副本时，Stagio 也只会跟着副本更新。

**两种方式都一样的部分**

- 抽查第一页、中间一页和最后一页的处理前后画面，任何一页对不上就整个放弃，什么都不改、不留下文件。逐页比对的结果是：平均差异不到 1.5（满分 255），明显不同的像素 0%。
- 带动画或超链接的文字会保持原样，不做转换。
- 每页约 8 秒，82 页大约 10 分钟，期间 PowerPoint 很忙，请在活动前做。**放映中不能开始**；如果做到一半开始放映，会自动暂停，放映结束后再继续。做图片的阶段可以随时按 **Stop**，什么都不会被改。
- 转换后这些装饰文字是图片，不能再当文字编辑。之后新加入的页面如果又带有这种文字，提示会再次出现，再做一次即可。

**还原加速前的版本**

- 这份文件在这台电脑上有备份时，文件名旁边会出现 **EARLIER VERSIONS**（文件还慢的时候，同一个位置显示 SLOW IN POWERPOINT，点开后备份也列在下面）。
- 点开会列出每份备份的时间和大小，按 **Restore** 两次（第二次显示 Confirm restore）就把那个版本放回原位：Stagio 先把文件现在的样子也存成一份备份，然后 PowerPoint 关掉文件、换回旧版本、再重新打开。所以还原之后反悔，可以用同样的方法换回来。
- 本机文件是逐字节换回；OneDrive / SharePoint 上的共享文件则是在 PowerPoint 里把旧版本“另存”回原来的位置，所有共享的人都会拿到，之后的修改（包括别人的）会被替换掉。**共享文件的还原还没在真正的 OneDrive / SharePoint 上测试过**；如果失败，旧版本会留在 PowerPoint 里打开，提示会告诉你用“另存为”放回去。
- 只能在主控电脑上做，放映中不能做。备份一共保留最近 5 份（加速和还原的备份合起来算），正在还原的那份不会被删。

## 调整版面

主控台右上角的 **Layout**（只在电脑上有）：

- **拖动分隔线**调整大小：投影片区和右边栏之间、Music 和 Output 之间、PROGRAM 和 PREVIEW 之间。双击分隔线恢复原来的大小。
- **预设**：Standard（标准）、Big program（PROGRAM 尽量大）、Slides only（只显示投影片）、Big slide list（页面列表变大）。
- **显示或隐藏**：Music、Output、Preview and notes、Notes、页面列表、Cue 栏。隐藏的部分快捷键照样可用。
- **Music and Output on the left**：把右边栏移到左边。
- **Slide list** 滑杆：页面列表缩略图的大小。

版面设置存在这台电脑的浏览器里，每台电脑、每支手机各自独立。手机和较窄的窗口固定使用分页显示，不受这些设置影响。

## 内嵌字体（Canva 等导出的文件）

从 Canva 导出的 .pptx 会把它用的字体（例如 Bebas Neue Bold、Beckett、Helvetica Now）内嵌在文件里，电脑上不需要安装也能在 PowerPoint 里正常显示。但 PowerPoint 的“导出单页图片”功能不会使用内嵌字体，会换成默认字体，文字变大、换行、互相重叠。0.4.0 及以前的缩略图和 PREVIEW 就是这样出错的。

从 0.4.1 起，Stagio 打开文件时会检查它是否用到“电脑上没有、靠文件内嵌”的字体：

- **没有**：照旧用快速方式生成缩略图。
- **有**：页面列表标题会显示 `EMBEDDED FONTS`，缩略图改为先导出 PDF，再转成图片（PowerPoint 导出 PDF 时会用内嵌字体），所以和投影画面一致。这种方式每张要慢一些，所以会把相邻的几页合在一次导出里处理。
- **放映中**（0.8.0 起）：还没有图的页面不再显示 `AFTER SHOW`。如果这份文件的 PDF 导出很快（每页 1.5 秒以内），放映中也直接做准确的图；否则先用 PowerPoint 的快速方式做一张**草图**，标上琥珀色的 `DRAFT`（字体可能和投影有一点不同），这一页一投到投影机上、或放映结束后，就自动换成准确的图。所以翻到下一页之前就能看到它大概的样子，不会像开盲盒。
- 投影机上的画面和 PROGRAM 的实时画面不受影响，因为它们直接显示 PowerPoint 自己画出来的画面。
- 用 PDF 方式连续失败 3 次时，会退回快速方式，先保证有图可看；这时标题显示 `FONTS MAY DIFFER`。按 **Reload all** 会再试一次。

PowerPoint 的“打印设置”里的页码范围会在导出时临时改动，导出后马上改回，文件不会被标成“已修改”。

## 自动 Cue

让某个 Cue 在放映翻到某一页时自己执行，例如“翻到诗歌那一页，音乐自动淡出”。

**设定方法一（在 Stagio 里）：** 先打开那份文件，Cues → Edit，在 Cue 下面勾选 **Run by itself at slide**，填页码，Save。页面列表里那一页会出现 `CUE n` 标记，Cue 按钮上显示 `auto @ 页码`。

**设定方法二（在投影片里）：** 在那一页的备注里写 `[cue: Break]`（写 Cue 名称的开头即可，不分大小写）或 `[cue 2]`（第 2 个 Cue）。做投影片的人可以自己安排，不用碰 Stagio。

规则：

- 只在**往前**翻到那一页、或从那一页开始放映时执行；往回翻不执行，免得回头看一眼音乐又响一次。
- 页面要停留约半秒才执行，快速连翻经过的页不会触发。
- 同一个 Cue 3 秒内不会执行第二次；刚手动按过的 Cue 也不会被页面紧接着再触发。
- 绑定的是那一页本身，不是页码：别人在前面插入、删除或移动页面后，Cue 仍然跟着那一页。那一页被删掉时，Cue 按钮显示 `auto slide deleted`。文件按文件名辨认，换了文件夹也认得。
- 执行时主控台和手机都会弹出提示（`Auto cue · 名称 · slide 页码`）；其中某一步失败也会显示。
- Cues 栏的 **Auto on / Auto off** 是总开关，关掉后两种方式都不触发。
- Stagio 启动时如果放映已经在进行，当前那一页的 Cue 不会被补执行。

注意：自动执行的 Cue 里如果有“跳到某页”“开始放映”这类动作，放映真的会跳页，设定时请留意。

## 隐藏 PowerPoint 的演示者视图

接上投影机并使用“扩展”模式时，PowerPoint 默认会在电脑屏幕上打开它自己的演示者视图，盖住 Stagio。Output → **PowerPoint presenter view** 选 **Hide**（默认）时，Stagio 每次开始放映都会先关掉它；选 **Show** 则打开。下次开始放映时生效。

这个设置属于那份 .pptx 文件（等同 PowerPoint 里“幻灯片放映 → 使用演示者视图”的勾选）。Stagio 改它时不会把文件标记为“已修改”，但如果之后文件因为别的修改被保存，这个勾选状态会一起存进去。

## 手机版面与设置

- **顶栏固定**：手机上往下滑时，最上面那一排（状态、Check、Awake、Full、时钟）一直留在屏幕上。
- **Prev / Black / White / Next 一直在**：在 Slides 页，这四个按钮排成一排固定在底部（分页标签上方），不管滑到页面列表的哪里都按得到。
- **Settings**：手机底部第五个标签（电脑上在右上角）。可以分别关掉上面两项，让投影片有更多空间；也可以调讲者备注的字号。这些设置只记在这台设备上，每支手机各自设定。

## 手机保持亮屏与全屏

- **Awake**：点一下，按钮变绿，手机屏幕不再自动熄灭；再点一下取消。选择会被记住，下次打开后在屏幕上任意点一下就会恢复。手机切到别的 App 再回来时会自动恢复（个别手机要在屏幕上再点一下）。
  - 原理：能用浏览器的“屏幕常亮”功能就用它；手机通过 `http://192.168…` 连线时浏览器不开放这个功能，Stagio 会改为在页面里播放一段看不见、没有声音的视频来保持亮屏。这时手机的通知栏可能显示“正在播放媒体”，属正常现象。
  - 如果点了之后按钮没有变绿，并提示无法保持亮屏，请把手机的“自动锁定 / 屏幕超时”调到最长。
- **Full**：隐藏浏览器的地址栏和工具栏（Android、iPad）。iPhone 的浏览器不提供这个功能，请用“加到主屏幕”；已经从主屏幕图标打开时不显示这个按钮。

## 防误操作与断线保护

- **End show 要按两次**：第一下按钮变红显示 Confirm end，3 秒内再按一次才会结束放映。放映中切换投影模式也一样。
- **关闭 Stagio 窗口前会询问**：放映进行中、有手机遥控连着、或正在加速或还原文件时，关窗口会先确认（关掉 Stagio 会让遥控和 Cue 失效，放映本身不受影响；加速做到一半就关，什么都不会被改）。
- **Reload all 要按两次**：它会重做所有缩略图，图片多的文件要十几分钟，所以第一下只会显示 Press again to remake all images，3 秒内再按一次才执行。
- **Cue 可以改成要按 Shift + 数字**：默认按 1–9 直接执行 Cue。怕不小心碰到数字键的话，在右上角 Keys 里把 Cue keys 改成 **Shift + 1 – 9**；之后单按数字不会执行，只会提示要按 Shift。Cue 按钮上的编号也会显示成 ⇧1、⇧2。
- **加速文件只能在主控电脑上开始**：它会改动文件，还会让 PowerPoint 忙上好几分钟；手机上只能看进度或按 Stop。
- **最近文件**：已经被移动、改名或删除的文件会变暗，标示 Not found。
- **窗口大小**：Stagio 会记住窗口上次的位置、大小和是否最大化；第一次在笔记本这类较小的屏幕上打开时，直接最大化。
- **断线会明说**：遥控端和电脑失去连线时，顶部出现红色提示条，LINK 显示 LOST；这时按任何按钮都会提示“No connection”，不会让人以为指令已送出。连线恢复后自动重连，手机从锁屏回来也会立刻重连。
- **PowerPoint 卡住时不会“补按”**：PowerPoint 忙碌期间排队超过时限的指令会被丢弃，不会在它恢复后一口气执行（例如连跳好几页）。此时状态栏显示 PPT BUSY，页面列表保留不清空。
- **Protected View 提示**：从下载或邮件打开的文件会停在 PowerPoint 的“受保护的视图”，Stagio 会说明原因，并提供 Enable editing 按钮。
- **Enter / Space 只翻页**：点过的按钮不会保留键盘焦点，之后按 Enter 不会重复触发它；按住按键不放也不会连续翻页。
- **只接受来自主控台的请求**：其他网页无法借这台电脑的浏览器向 Stagio 发指令；PIN 和二维码只在电脑的主控台上显示，不会发给已连线的手机。

## 缩略图永远是真实样子

缩略图、PREVIEW 和手机上看到的页面，只有在确定是“这一页现在真正的样子”时才会显示：

- **不显示错的图**：还没准备好的页面会写明原因：`PREPARING`（正在生成）或 `WAITING`（你正在 PowerPoint 里操作，暂停中）。带内嵌字体、而这台电脑没有那些字体的文件，放映中先显示标着 `DRAFT` 的草图，准确的图好了就自动替换。页面被改过、新图还没好时，旧图会变暗并标上 EDITED。
- **用投影画面当缩略图**：放映时，一页在投影机上停稳约 1.5 秒、动画都播完后，Stagio 会把投影画面直接存成这一页的缩略图。这就是观众看到的样子，而且不占用 PowerPoint。以下情况不会截图：画面还在变化（切换效果、影片），黑屏或白屏，鼠标停在投影画面上（PowerPoint 会显示放映工具列），或者投影画面被其他窗口挡住。
- **不管投影机是什么分辨率、大小或缩放比例，看到的都是完整的一页**（0.7.1 起）：截图按投影机那个屏幕的实际像素来取，并且只取投影片本身，去掉屏幕形状不同而多出的黑边，所以 PROGRAM 和缩略图跟 PowerPoint 的演示者视图一样，显示整页、尽量放大。另外有两道保险：
  - 放映窗口的位置跟它所在的屏幕对不上时（例如两个屏幕缩放比例不同、而系统没有提供正确的坐标），就不截图，PROGRAM 改用这一页的图片，并说明原因。
  - 这一页已经有 PowerPoint 自己做的图片时，投影截图必须跟它相符才会被存成缩略图；看起来被裁掉或偏移的截图会直接丢弃。
  - 0.7.0 以前从投影机截下来的缩略图，在缩放比例不同的屏幕上可能被裁掉一大块，升级后这些旧截图不再使用，会自动重新生成。
- **检测更完整**：页面的位置、大小、旋转、文字、字体、字号、粗体、文字颜色、图片裁切、背景和版式有改动，都会重新生成缩略图。填充色、线条颜色这类改动没有列入，因为检测成本太高；这类页面一投到投影机上，就会用投影画面自动更正，也可以按 **Reload all**。
- **进度和剩余时间**：页面列表标题会显示 `PREPARING IMAGES 12/82 · ABOUT 6 MIN`。
- **不在你编辑时抢 PowerPoint**：你正在 PowerPoint 里打字或点击时，Stagio 暂停生成缩略图，停手 4 秒后再继续，以免 PowerPoint 卡住。

## 调整页面顺序、隐藏的页面

- **直接在 Stagio 里调整顺序**（电脑上的主控台）：把页面列表里的一页拖到别的位置，PowerPoint 就会把那一页移过去，放映中也可以（正在投影的那一页不会变）。移动后文件还没存，页面列表上方会出现 **Save file**，按一下就存进文件；不存的话，关掉 PowerPoint 时它会问你。
- **隐藏的页面**：在 PowerPoint 里设成“隐藏幻灯片”的页，页面列表里会变暗、页码划掉，并标上 HIDDEN，标题栏也会写“N hidden”。放映时 PowerPoint 会跳过它们，所以 PREVIEW 显示的是下一张没隐藏的页；直接点隐藏的页仍然可以投出去。在 PowerPoint 里改了隐藏或取消隐藏，Stagio 几秒内就会跟着更新（放映中最慢约 30 秒）。

## 现场有人同时修改投影片

Stagio 会自动侦测改动：改过的页会更新缩略图，并标上琥珀色 EDITED，保留 30 秒；新增或删除的页面会立即出现在列表里。

PowerPoint 同一时间只能处理一件事，而且在图片很多的文件上，渲染一张缩略图要 1–3 秒。为了不拖慢放映，Stagio 的后台工作这样安排：

- **放映期间**：只检查和生成投影中的页及后面几页，下一页优先。等多久才动手，看这份文件出图有多快：出图快的文件，停止翻页约 1.2 秒就做（以前要 8 秒，连续翻页时后面的页一直没有图）；出图慢的文件等 2.5–6 秒，保证翻页不会排在出图后面。离投影较远的页，会等你翻到附近、或放映结束后再处理。
- **放映前**（PowerPoint 处于编辑模式）：全速生成所有缩略图。
- **缩略图存在硬盘上**（安装版在 `%USERPROFILE%\.onedesk\thumbs`）：页面内容没变就不会重新生成，重开 Stagio 也能直接使用。每页存两张 JPEG：页面列表用小图（约 5–15 KB），PROGRAM / PREVIEW 用大图，手机第一次载入一份 80 页的文件只需不到 1 MB。
- **PROGRAM 画面**：如果放映窗口在屏幕上可见（接上投影机并设成 Extend），会直接截取放映画面（只取投影片本身，不含屏幕形状不同而多出的黑边），每秒更新一次，不占用 PowerPoint，左上角显示 LIVE CAPTURE。PROGRAM 和 PREVIEW 的框按投影片的长宽比例显示（4:3 的文件就是 4:3 的框）。Output 里 Show slides on 列出的每个屏幕会显示实际分辨率和缩放比例。拿不到实时画面时（例如只有一个屏幕、Stagio 在放映窗口前面），改用这一页的图片，并用琥珀色标示 IMAGE · NOT LIVE（鼠标移上去会说明原因）。这张图片是所有动画都出现后的样子，所以如果这一页的动画还没播完，画面底部会写明投影上目前实际显示到第几步。

**建议：** 活动前先打开文件和 Stagio，等缩略图全部生成完再开始放映。如果文件里有很大的图片（像从 Canva 导出的文件），在 PowerPoint 里执行“文件 → 压缩图片”，翻页和缩略图都会快很多。

**让别人在他们自己的电脑上同时修改：** 把 .pptx 放到 OneDrive 或 SharePoint，所有人从那里打开，并在 PowerPoint 左上角打开「自动保存」。PowerPoint 会把共同编辑的内容同步到这台电脑，Stagio 再跟着更新。标题旁会显示状态：

- 绿色 CO-EDIT ON：设置正确。
- LOCAL FILE 或 AUTOSAVE OFF：别人的修改不会同步过来。

## 音乐：用你平常的播放程序

Stagio 不需要任何音乐账号，也不连接任何音乐服务：它控制的是这台电脑上正在放音乐的程序。

- **Windows**：凡是出现在 Windows 自己的媒体控制里的程序都可以（按音量键时出现的那个小框）：Spotify、Apple Music、“媒体播放器”、浏览器里的音乐或影片、VLC 4、装了插件的 foobar2000 等。
- **Mac**：“音乐”App 或 Spotify（macOS 不让其他程序读取任意播放器在放什么）。
- **自动跟随**（默认）：Stagio 跟着正在放音乐的程序；已经在跟的那个继续放着时，不会因为别的程序（例如浏览器里的一段影片）开始出声就跳过去。也可以在 Music 区右上角的选单里固定选一个程序。
- 能做的：播放/暂停、上一首/下一首、点进度条跳到那个位置（程序支持的话）、显示歌名和封面、调整那个程序自己的音量、淡入淡出。歌单请直接在那个程序里选。
- 淡入淡出只调那个程序自己的音量，系统音量和其他声音不受影响。
- 第一次用：先在播放程序里放一首歌（之后暂停也可以），主控台就能控制它。之后 Stagio 会记住这个程序，下次它没开时，Music 区和开场前检查会出现 **Open** 按钮。
- 右上角的 **Off** 关掉音乐控制，Cue 里的音乐动作会被跳过。

注意：用串流服务在公开场合放音乐，要遵守那个服务自己的使用条款和当地的版权规定。

### 音乐淡入淡出（0.7.2 起不再有“哔哔啵啵”的杂音）

Windows 改变一个程序的音量时是立刻生效的，所以每改一次，声波就会断开一下。0.7.2 以前，淡入淡出大约每 0.1 秒改一格，每格就是一个小爆音，连起来像炸麦的“哔哔啵啵”。用测试音实测：断口平均是声波高度的 4%，最大到 20%。

现在淡入淡出在后台的音频程序里一次跑完：先找到播放程序的音量控制，之后每约 2 毫秒调一点，按耳朵的感觉均匀变化（每秒同样多分贝，降到 −50 dB 后静音）。实测断口约 1%，没有超过 10% 的，听起来是连续的。另外：

- 拖 Level 滑杆或 Cue 设定音量时，用 0.3 秒滑过去，而不是直接跳（直接跳也会“啵”一声）。
- 淡出完成并暂停后，要等播放程序真的停下来才把音量调回原值，结尾不会突然冒出一小段原音量的声音。
- 播放程序刚打开、还没播放过就淡入时，它的声音一出现就立刻调成静音，再开始淡入，开头不会先大声响一下。
- 淡出做到一半又按淡入，会从当时的音量平滑往回升，不会跳。


### 从指定音量淡到指定音量

Music 区淡入淡出按钮下面一行：**Fade from [ ] to [ ]**，再按 **Fade**（秒数用上面那一格）。

- **from** 留空：从现在的音量开始。填了数字：先在 0.3 秒内滑到那个音量，再开始淡。
- **to** 是结束的音量。例如 80 → 30：讲话时把音乐压低但不停；30 → 80：讲完再升回去。
- **to 填 0**：和 Fade out 一样，结束时暂停，并把音量放回原值，下次播放不会是静音。
- 音乐停着时按 Fade：从 from（留空就从静音）开始播放，再淡到 to。
- 淡到的音量会成为“正常音量”，之后按 Fade in 会回到这个音量。
- 两个数字会记在这台设备上。Cue 里也有同样的步骤：**Music · fade from level to level**。

### 系统音量平滑过渡

Output 区的 System 滑杆、以及 Cue 里的 “Output · system volume”，会用约 0.4 秒从原来的音量滑到新的音量，而不是一下子跳过去（突然跳会“砰”一声）。

### 放映中插入或删除页面

可以直接在 PowerPoint 里插入或删除页面，放映会保持在原本那一页（PowerPoint 会自动调整页码）；删除正在放映的那一页，会跳到下一页。Stagio 用每页固定不变的 ID 来对应页面，约 0.6 秒内就会同步页面列表、PROGRAM 和 PREVIEW；点缩略图跳页也以 ID 为准，不会因为页码变动而跳错。

### 没有 Wi-Fi，或手机连不上电脑时（0.8.0 起；Mac 用手机热点代替 Stagio Wi-Fi）

在 Remote 对话框下方展开 **No Wi-Fi, or the phone can't reach this PC?**，有两种方式：

**Stagio Wi-Fi（iPhone 和 Android 都可以，推荐）**

- 按 **Start**，这台电脑会开一个自己的小 Wi-Fi 网络（名字是 `Stagio-XXXX`）。场地没有 Wi-Fi，或场地的 Wi-Fi 把手机和电脑隔开时都能用。
- 手机先扫第一个二维码加入这个网络，再扫第二个二维码打开 Stagio。网络名称和密码每次都一样，手机加入过一次之后会自动重连。
- 这个网络没有上网功能：手机如果提示“此网络无法上网”，请选择保持连接。电脑本身的网络连线通常不受影响（视 Wi-Fi 网卡而定）。
- 如果手机连上了但网页打不开，可能是 Windows 防火墙挡住了 Stagio 在“公用网络”上的连线：Windows 安全中心 → 防火墙 → 允许应用通过防火墙，勾选 Stagio 的“公用”。（这台电脑上 Stagio 已经允许。）
- Stagio 关掉时，这个网络也会关掉。

**蓝牙（Android 手机，Chrome）**

- 适合完全没有任何 Wi-Fi 的情况。按 **Start** 后，Android 手机用 Chrome 打开 https://ngxu.github.io/stagio/remote/（对话框里有二维码），输入 PIN，按 **Connect**，在列表中选这台电脑。
- 第一次打开这个页面需要上网（流动数据也可以），之后没有网络也能用；可以加到主屏幕。
- 蓝牙版只能控制：上下页、黑屏/白屏、开始/结束放映、Cue、音乐淡入淡出和播放/暂停；显示页码和状态，但不显示投影片画面（蓝牙太慢，传不了图片）。
- iPhone 的浏览器不支持网页蓝牙，iPhone 请用 Stagio Wi-Fi。
- 每个指令都带 PIN；PIN 错误时指令会被忽略，同一支手机连续错 8 次会被挡 5 分钟。

### 手机连不上时

1. 手机必须连同一个 Wi-Fi，不能用流动数据或访客网络。部分路由器会阻止设备之间互相连线（“AP 隔离”），需要关闭。
2. 电脑上的 Stagio 必须正在运行。
3. 第一次运行 Stagio 时 Windows 会问是否允许它使用网络，要选“允许”（专用和公用网络都勾）。
4. 网页完全打不开时，可能是电脑上的安全软件拦截了 7300 端口，请在里面允许 Stagio 或 7300 端口。
5. 用聊天软件扫码打不开时，改用手机自带的相机或浏览器，或者手动输入网址再输入 PIN。

## 快速自动检查

不需要放映，一分钟内跑完：helper 能否启动、过期指令是否被丢弃、配置文件损坏能否恢复、自动 Cue 的触发规则、淡入淡出、三个版本的功能、节目流程（用替身代替 PowerPoint 和音乐）。加上 `--server`（需先 `npm run dev`；可以用 `STAGIO_EDITION` 当作 Lite 或 Extra 启动）还会检查安全拦截、手机登录、增量推送，以及这个版本拒绝它没有的功能。在 Mac 上用 `--no-helper`（跳过 Windows 的 helper）：

```bash
node test/checks.js --server
```

## 压力测试

npm run stress -- "D:\路径\测试.pptx"

## 已知限制

- 快捷键只在主控台窗口在前台时有效；开始放映时 PowerPoint 可能抢走焦点，点一下主控台即可。
- Output 区的 Show slides on（放映在哪个屏幕）写入 PowerPoint 自己的显示器设置（`UseMonMgr` 和 `DisplayMonitor`），下次开始放映时生效。**还没有在接了第二个屏幕的电脑上验证过**；如果不生效，请在 PowerPoint 的“幻灯片放映 → 监视器”里选。
- 隐藏演示者视图（Output → PowerPoint presenter view）同样**还没有在接了投影机的电脑上验证过**：设置确实写进了 PowerPoint，但要接上第二个屏幕才看得出效果。
- 手机的 Awake（保持亮屏）**还没有在真实手机上验证过**。按钮变绿表示保持亮屏的机制正在运行，但个别手机可能仍会熄屏；活动前请实际放 2–3 分钟确认，不行就把手机的自动锁定时间调到最长。
- Android 手机“加到主屏幕”后可能仍带浏览器地址栏（需要 HTTPS 才能完全全屏）；可以改按顶部的 Full。iPhone 的浏览器不允许网页全屏，请用“加到主屏幕”。
- 切换音频输出设备会改变整台电脑的默认输出。
- **Windows 版 PowerPoint 处理某些 Canva 文件特别慢**：我们实际遇到的一套 Canva 投影片每页背景都有约 2,800 个带元音符号的希伯来文字符，用的字体（Helvetica Now）却没有希伯来字母，Windows 要逐字找替代字体再排版。实测不经过 Stagio、直接让 PowerPoint 翻页，每页要 3–7 秒；生成一张缩略图要 2–6 秒，删掉这些希伯来文后只要 0.25–0.6 秒（快约 10 倍）。Mac 用的文字排版引擎不同，所以没有这个问题。解决办法：用 Stagio 的“加速”（见上文）；或请做投影片的人在 Canva 里把背景的希伯来文做成图片再导出。只把这些文字改成带希伯来字母的字体，缩略图会变快，但 PowerPoint 放映时翻页并不会明显变快（实测中位数只从 5.4 秒降到 4.9 秒）。
