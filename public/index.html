Stagio Wi-FiiPhone and Android

This PC opens a small Wi-Fi network of its own for the phones. Works with no Wi-Fi at the venue, or when the venue Wi-Fi keeps phones apart from the PC. Phones on it have no internet.

  • If the phone says the network has no internet, choose to stay connected.
  • If the phone joins but the page doesn't open: Windows may be blocking Stagio on this kind of network. Allow Stagio for public networks in Windows Security → Firewall → Allow an app.
  • It stays on while Stagio runs; the name and password are always the same, so phones join again by themselves.
Phone hotspotiPhone and Android

A Mac can't open a Wi-Fi network of its own, but it can join the phone's:

  1. On the phone, turn on Personal Hotspot (iPhone) or Hotspot (Android).
  2. On this Mac, choose that phone's network in the Wi-Fi menu.
  3. Close this window and click Remote again: the code above then points at this Mac on the phone's network. Scan it with that same phone.
BluetoothAndroid phones, in Chrome

For when no Wi-Fi works at all. The phone controls slides, black/white, cues and fades; it shows the slide number, not pictures. iPhones can't use Bluetooth from a web page: use Stagio Wi-Fi.

  • The first time it needs internet (mobile data is fine); after that it works offline. Add it to the home screen.
  • Tap Connect, choose this PC in the list, and enter the PIN above.
Install on the phone's home screen
  • iPhone / iPad (Safari): open the link, tap Share, then Add to Home Screen.
  • Android (Chrome): open the link, tap ⋮, then Add to Home screen.
  • Mac (Safari): open the link, then File → Add to Dock.
  • The icon opens Stagio full screen. The first time, enter the PIN once.
  • The icon remembers this PC's address. If it stops connecting, the PC's address has probably changed: scan the new code and add it again. Reserving the address in the Wi-Fi router stops this from happening.
Phone can't connect?
  • The phone must use the same Wi-Fi, not mobile data or a guest network. Some routers block devices from seeing each other (“AP isolation”); turn that off or use another network.
  • Keep Stagio running on this PC.
  • The first time Stagio runs, Windows asks whether to allow it on the network: choose Allow, for both private and public networks.
  • If the page never loads, security software on this PC may be blocking port 7300. Allow Stagio / port 7300 there.
  • QR scanners inside chat apps sometimes fail; open the link in the phone's normal browser, or type the address and use the PIN.

Cues

Steps run top to bottom. Fades run in the background, so the next step starts right away.

A cue can also run by itself when the show reaches a slide going forward (not when stepping back). It stays with that slide if slides are added or moved. Whoever builds the slides can do the same by writing [cue: name] in a slide's notes.

Run of show

The parts of the event, in order. Next part does what each part needs: opens the speaker's file and starts its slide show, shows the countdown on the projector, brings the music in. The next file is opened ahead of time, so the change is quick. Planned minutes tell you how far ahead or behind you are.

Layout
